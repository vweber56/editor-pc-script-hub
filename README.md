## About Editor

Editor gives you a dedicated space to draft and tighten Roblox Lua before you move that text into an executor. It is built around editing, not around shipping a massive in-app catalog of ready-made scripts.

People who look for a Roblox script editor, Lua tooling tied to executors, or a simple Windows desktop surface will find that this project stays narrow on purpose: prepare script content cleanly, then hand it off to whatever execution path you already use.

## Getting Started

Clone the repo and move into the project folder:

```bash
git clone https://github.com/vweber56/editor-pc-script-hub.git
cd editor
```

When a packaged Windows build is present, start it with:

```powershell
.\EditorExecutor.exe
```

Per the project profile, Editor is the script-editing half of a Roblox executor workflow. Read the repo contents and any legal terms before you combine scripts with Roblox or third-party tools.
